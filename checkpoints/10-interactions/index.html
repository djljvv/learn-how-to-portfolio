02CSS turns a list into a layoutstyles.css

Three columns, one rule.

A selector such as .project-grid targets an HTML class. Inside its braces, declarations describe how that element looks.

display: grid creates a grid. Three equal tracks hold the project cards, and gap adds space between them. Below 760 pixels, a media query changes this to one column. Resize your window to try it.

/* A period selects an HTML class. */
.project-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

/* Adapt to a narrower viewport. */
@media (max-width: 760px) {
  .project-grid {
    grid-template-columns: 1fr;
  }
}
03JavaScript responds to youscript.js

An event becomes a change.

querySelector finds an HTML element. addEventListener runs a function when you click it. The function adds one to a number and updates the visible text.

Count: 0

This number lives in memory. Reloading the page resets it.

// Find two elements; start counting at zero.
const button = document.querySelector('#counter-button');
const output = document.querySelector('#counter-output');
let count = 0;

// Run this function on each click.
button.addEventListener('click', () => {
  count += 1;
  output.textContent = `Count: ${count}`;
});
