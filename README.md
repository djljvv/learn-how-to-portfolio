# learn-how-to-portfolio
An example website that runs through the basics of how to make a portfolio website.

Open `index.html` in a browser to explore the portfolio. No dependencies or build step are required; keep all five HTML files, `styles.css`, and `script.js` in the same folder.

- `tutorial.html`: a 12-step walkthrough with code, explanations, and expected results.
- `html-glossary.html`, `css-glossary.html`, `javascript-glossary.html`: alphabetized references to the features used in the site, linked from the bottom of each homepage code lesson.
- `styles.css`: the shared visual theme, layouts, responsive rules, and commented illustrations.
- `script.js`: commented, independently guarded notes, filter, and counter interactions on the homepage.

Page links use native browser navigation in the same tab. All learning pages work without JavaScript. Code excerpts are teaching examples; edit the source files to change the actual site.

To check an edit, reload the page, try every filter and the counter, toggle learning notes, expand and collapse lessons, and follow the guide and dictionary links back to their examples. Repeat at a narrow viewport and with keyboard navigation. With JavaScript disabled, content and links should still work and JavaScript-only controls should stay hidden.
